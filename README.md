# Location

## О проекте

Этот проект создан в рамках итоговой аттестации (виртуальной стажировки) SkillFactory для разработки REST API, предназначенного для мобильного приложения ФСТР (Федерация Спортивного Туризма России). Приложение помогает туристам отправлять данные о перевалах, упрощает обработку информации и позволяет отслеживать статус модерации объектов через мобильное приложение для Android и iOS.

## Цель

- Упростить туристам задачу передачи информации о перевалах.
- Сократить время обработки заявок до 3 дней.
- Позволить модераторам ФСТР оперативно верифицировать данные.
- Дать пользователям возможность отслеживать статус своих заявок и просматривать базу перевалов.

## Функционал REST API

### POST /submitData/

Позволяет туристу отправить данные о перевале:
- Координаты объекта и его высота
- Название объекта
- Несколько фотографий
- Информация о пользователе (ФИО, email, телефон)

### GET /submitData/<id>/

Получить информацию о конкретном перевале по его ID, включая статус модерации.

### PATCH /submitData/<id>/

Позволяет редактировать данные перевала, если он находится в статусе `new`. Редактируются все поля, кроме ФИО, email и телефона пользователя.

#### Ответ:
- `state: 1` — успех
- `state: 0` — ошибка
- `message` — причина неудачи

### GET /submitData/?user__email=<email>

Получить список всех объектов, которые пользователь с данным email отправил на сервер.

## Статусы модерации

- `new` — новая заявка
- `pending` — заявка принята модератором в работу
- `accepted` — заявка успешно прошла модерацию
- `rejected` — заявка отклонена

## Переменные окружения для работы с БД

- `FSTR_DB_HOST` — путь к базе данных
- `FSTR_DB_PORT` — порт базы данных
- `FSTR_DB_LOGIN` — логин для подключения
- `FSTR_DB_PASS` — пароль для подключения

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Aleksandr-hub-cyber/Location.git
   cd Location
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение согласно инструкции (например, через uvicorn или flask).

## Пример использования

Отправка данных о перевале:
```json

{
  "coords": {"lat": 43.123, "lon": 44.321, "height": 2340},
  "title": "Перевал Лагерь",
  "images": ["base64string1", "base64string2"],
  "user": {
    "name": "Иванов Иван Иванович",
    "email": "ivanov@email.com",
    "phone": "+79998887766"
  }
}
```
